# Размещение на SpaceWeb

Домен: https://obogrevsistem.ru/

Тариф виртуального хостинга SpaceWeb использует каталог `public_html`. Docker для текущего размещения не требуется.

## Текущая публичная сборка

Сайт публикуется в режиме прямой связи: телефон и email вместо формы сбора заявок. Галереи, фильтры, навигация и страницы решений работают как обычно. Тестовые формы, черновик согласия для формы, страница благодарности, секреты и журналы обращений не загружаются на хостинг. С 27 октября 2026 года подключена Метрика 113826221 после согласия посетителя. Сохранение рекламных идентификаторов для отправки формы в этой сборке отключено.

Локальная версия с формами сохранена без изменения. Чтобы включить их публично, необходимо завершить документы с реквизитами оператора, настроить доставку писем и развернуть серверный обработчик для выбранного тарифа. Простая загрузка `server.py` в public_html не запускает Python-приложение и не используется.

## Подготовить файлы для повторной загрузки

Из корня репозитория:

```sh
python website/build.py
python website/export_shared.py --output output/sweb-public --https --metrika-id 113826221
```

В `output/sweb-public` будут только публичные файлы. Загрузите **содержимое** этого каталога в `public_html` по FTPS, сохранив исходную резервную копию. Не загружайте всю рабочую папку или `.env`.

Ключ `--https` включает 301-перенаправление HTTP → HTTPS и www → основной домен. Используйте его только после установки действующего сертификата. Исключение для ACME-проверок сохранено. SSL-сертификат управляется в панели SpaceWeb; там же настраивается его автоматическое продление.

При первоначальном размещении 11 октября 2026 года заказан Let's Encrypt. Пока провайдер выпускает сертификат, сайт работает по HTTP. В приватном каталоге аккаунта `osystem-deploy` установлен временный обработчик `enable_https_once.py`: раз в пять минут он проверяет сертификат основного домена и www, затем атомарно включает перенаправление. После успеха задача удаляет только собственную строку Crontab. Если конфигурация сайта изменилась вручную, она не перезаписывается. Максимальный срок ожидания — 24 часа, результат сохраняется в `https-status.json` вне public_html.

Первая проверка на сервере выполнена успешно: Python запускается, задача ожидает сертификат. Если после суток HTTPS не появился, проверьте статус заказа в разделе SSL и файл `osystem-deploy/https-status.json`; после устранения причины заново запустите проверку или примените `--https` вручную. Состояние «pending» не означает, что сертификат уже установлен.

Экспорт содержит sitemap.xml с адресами домена, robots.txt, свою страницу 404 и защитные HTTP-заголовки. DNS домена направлен на хостинг; при обновлении содержимого сайта менять DNS не нужно.

Обычный локальный запуск по-прежнему выполняется через `Запустить сайт.cmd` или `python website/server.py --open`.

Пароли хостинга и почты не хранятся в репозитории.

## Метрика 113826221

Счётчик загружается только после «Разрешить» в панели аналитики и только на obogrevsistem.ru / www.obogrevsistem.ru. Отказ сохраняется; изменить выбор можно в подвале. Локальная проверка не отправляет просмотры. Пиксель noscript намеренно не добавлен, чтобы не отправлять данные до выбора посетителя.

В коде подготовлены JavaScript-события phone_click и email_click. В интерфейсе Метрики необходимо создать соответствующие цели типа JavaScript-событие, затем выбрать счётчик и цели в Директе. Эти события означают нажатия, а не состоявшийся звонок или отправленное письмо. Цели в аккаунте и рекламные кампании этим развёртыванием не изменялись.

Параметры инициализации включают webvisor, clickmap, trackLinks, accurateTrackBounce и ecommerce dataLayer из предоставленного владельцем кода. Событий покупок на сайте нет. CSP разрешает только mc.yandex.ru для скрипта, изображений и соединений. Защита от встраивания сохранена. Просмотр записей Вебвизора в кабинете не проверен; для полного набора функций могут потребоваться дополнительные разрешения CSP, согласованные отдельно.

Проверено: все страницы содержат элементы выбора аналитики; отказ сохраняется после обновления; после согласия появляется скрипт счётчика; логика событий и однократная инициализация проходят локальную проверку. Наличие визитов и конверсий в отчётах аккаунта требует отдельной проверки в Метрике. Реквизиты оператора и документы опубликованы 28.10.2026..

Политика публичной версии берётся из business.py, а не из черновика локальной формы. На сайте также опубликовано отдельное /analytics-consent/. Выбор аналитики учитывает дату и версию, действует 180 дней.
