# OSystem · ОбогревСистем

Сайт компании «ОбогревСистем»: 33 страницы, решения и услуги по кабельному обогреву, реальные фотографии монтажа, адаптивная вёрстка и формы обращения.

Публичный домен: **http://obogrevsistem.ru/**. HTTPS включается автоматически после выпуска и проверки сертификата. Для виртуального хостинга подготовлена отдельная сборка с прямыми контактами вместо тестовых форм. [Как обновлять версию на SpaceWeb](website/SPACEWEB.md).

## Скачать и запустить на Windows

1. На странице репозитория нажмите **Code → Download ZIP** и распакуйте архив целиком.
2. Установите [Python 3.11 или новее](https://www.python.org/downloads/). При установке включите **Add python.exe to PATH**.
3. Дважды нажмите **Запустить сайт.cmd** в корне распакованной папки.
4. Откроется **http://127.0.0.1:8766/**. Окно запуска оставьте открытым; для остановки нажмите в нём **Ctrl+C**.

Для локального просмотра не нужны Node.js, npm, Docker, пароль от почты или аккаунт Codex. Все необходимые фотографии и шрифты включены. При первом запуске браузер открывается автоматически.

На Linux/macOS с Python 3.11+:

```sh
cd website
python3 server.py --open
```

Можно также клонировать репозиторий:

```sh
git clone https://github.com/droseee420-cloud/OSystem.git
cd OSystem/website
python server.py --open
```

## Формы и публикация

По умолчанию сайт работает **в режиме локальной проверки**. Тестовые заявки сохраняются на вашем компьютере, внешние письма не отправляются, Яндекс Метрика отключена. Не вводите реальные персональные данные при проверке черновых правовых документов.

Для публичного запуска нужны пароль приложения Яндекс Почты, домен с HTTPS, реквизиты оператора и окончательные документы по обработке данных. Для аналитики — номер счётчика Метрики и настройка целей в Директе. Секреты задаются в локальном `.env`, который исключён из Git.

Подготовлены Dockerfile, Docker Compose и пример Nginx для своего сервера. Это серверное приложение: **GitHub Pages не поддерживает отправку этих форм**. Публичный репозиторий предназначен для скачивания исходников и развёртывания.

## Редактирование

Основные файлы находятся в `website/`:

- `build.py`, `content.json`, `cases.json` — страницы, тексты и фотографии;
- `public/assets/site.css` — дизайн;
- `public/assets/site.js` — интерфейс и формы;
- `server.py` — локальный сервер и обработка заявок;
- `REBUILD.cmd` — пересборка HTML после изменения текстов.

Репозиторий содержит готовые страницы: выполнять пересборку перед первым запуском не требуется. Исходные фотографии, рабочие документы, пароли и журналы обращений не публикуются.
